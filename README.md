# software-98.github.io

The Software-98 developer website, served by GitHub Pages at
https://software-98.github.io.

- `app-ads.txt`: the authorised ad sellers for FoodTrax's AdMob account. AdMob
  reads it from the root of the developer website listed on Google Play, so it
  must stay at the root of this site.
- `index.html`: the landing page.
